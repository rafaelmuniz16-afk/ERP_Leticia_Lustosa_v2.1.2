# ERP Letícia Lustosa v2.1.2 — Frontend

Publicação do frontend estático do ERP, com Aurora Intelligence e Inativação.

## GitHub Pages

Após criar o repositório, envie os arquivos e habilite Settings → Pages → Deploy from a branch → main → /(root).

## Importante

O código do Google Apps Script não está incluído nesta publicação. A URL da implantação atual do Apps Script permanece configurada no frontend em `js/core/config-state.js`. Confirme as permissões do endpoint e faça a homologação com cuidado antes de ativar o site público.

Não compartilhe chaves Groq, dados de casos ou credenciais no repositório.
